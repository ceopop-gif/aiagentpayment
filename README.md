# AnnyPay AI Commerce + Payment

AI Operating System for Commerce & Payment

**Flow:** Prompt → Store → Product → SalePage → Payment → Order → Settlement

## Current prototype

- ChatGPT-style AI Home
- Merchant / KYC status
- Multi-store dashboard
- Product management
- AI SalePage area
- Payment / Payment Link / Transaction / Settlement
- Orders
- Customers
- Analytics / Reports
- Settings / Security / AI Audit
- Responsive mobile layout

## Live demo

https://annypay-ai-commerce-ceopop-1344.vercel.app

## Run locally

เปิด `index.html` ด้วย browser ได้ทันที หรือใช้ static web server ใดก็ได้

## Product direction

AnnyPay ถูกออกแบบเป็น AI Commerce + Payment Orchestration Layer ที่ให้ Merchant สั่งงานด้วยภาษาธรรมชาติ โดย Payment จริงต้องอ้างอิงสถานะจาก Payment Provider, KYC และ Webhook ที่ตรวจสอบแล้วเท่านั้น
